================================================================================
🏛️ GUIA DEFINITIVO DE ATUALIZAÇÃO, TUNING E BLINDAGEM DO FREEBSD 15.1
================================================================================
Hardware: Intel Core 12ª Geração (Alder Lake-P / Iris Xe Graphics), 16 GB RAM
Ambiente: KDE Plasma 6 Wayland, OpenZFS, Bhyve Hipervisor, Submódulos Soberanos
================================================================================

Execute os blocos abaixo no terminal do host FreeBSD como usuário operador (com
privilégios de elevação doas/sudo configurados).

--------------------------------------------------------------------------------
PASSO 1: SINCRONIZAÇÃO DE TODOS OS REPOSITÓRIOS (BANCADA E PRODUÇÃO)
--------------------------------------------------------------------------------

1.1. Atualizar e sincronizar todos os componentes do ecossistema:
upall

Caso o alias 'upall' não esteja no PATH nesta sessão, execute manualmente:
cd ~/Documents/Environment
git pull --recurse-submodules
git submodule update --init --recursive
upsh && uprc && uped

1.2. Recarregar o shell canônico interativo:
resh

--------------------------------------------------------------------------------
PASSO 2: PROPORÇÃO DE MEMÓRIA 16 PARTES E TUNINGS DE KERNEL SYSCTL
--------------------------------------------------------------------------------
Fórmula Proporcional (cálculo dinâmico sobre hw.realmem || hw.physmem):
- 1/16 VM Bhyve / NetBSD (1 GB para 16 GB RAM; mínimo 1 GB, teto 2 GB)
- 4/16 ZFS ARC           (4 GB para 16 GB RAM; mínimo 1 GB, teto 4 GB)
- 11/16 Host DRM         (11 GB livres para KDE Plasma 6, Browsers, Compilações e GPU)

2.1. Executar as receitas canônicas de dimensionamento de ARC e parâmetros de kernel:
sh ~/Documents/Environment/Setup/freebsd/desktop/system/zfs-arc.sh
sh ~/Documents/Environment/Setup/freebsd/common/system/sysctl.sh

2.2. Verificar parâmetros ativos em runtime:
sysctl vfs.zfs.arc.max vfs.zfs.arc.min kern.maxfiles kern.maxfilesperproc kern.ipc.shmmax kern.ipc.shmall

--------------------------------------------------------------------------------
PASSO 3: BLINDAGEM DE GPU (INTEL GEN 12), VA-API, ISOLAMENTO WI-FI E TTYS
--------------------------------------------------------------------------------
Mitigações aplicadas:
- HuC firmware ativado (compat.linuxkpi.i915_enable_guc="2") para aceleração de vídeo
- Estados profundos de display e economia desativados (PSR=0, PSR2=0, FBC=0, DC=0)
- Isolamento automático devd entre cabo Ethernet (re0) e Wi-Fi (wlan0)
- Teclas Ctrl+Left / Ctrl+Right mapeadas para saltos de palavras no console vt(4)

3.1. Executar as receitas de sistema e console:
sh ~/Documents/Environment/Setup/freebsd/desktop/system/system.sh
sh ~/Documents/Environment/Setup/freebsd/desktop/system/ttys.sh

3.2. Instalar bibliotecas de aceleração VA-API (Intel Media Driver iHD):
sudo pkg install -y multimedia/libva-intel-media-driver multimedia/libva-utils

3.3. Testar a aceleração de hardware VA-API:
vainfo

--------------------------------------------------------------------------------
PASSO 4: VIRTUALIZAÇÃO BHYVE E HYPERVISORS SOB DEMANDA (SEM AUTOSTART)
--------------------------------------------------------------------------------
Para preservar 11 GB de RAM para o host gráfico, o autostart das VMs no boot
é desativado (vm_list=""), economizando memória cabeada (wired memory). A receita
calcula automaticamente o limite de 1/16 da RAM física total:

4.1. Aplicar a receita de configuração do hipervisor Bhyve:
sh ~/Documents/Environment/Setup/freebsd/container/bhyve.sh

4.2. Garantir autostart desativado no rc.conf:
sudo sysrc vm_list=""

4.3. Ciclo de vida da VM Debian (lx) sob demanda:
lx -s
lx
lx -c

4.4. Ciclo de vida da VM NetBSD (nb) sob demanda:
nb -s
nb
nb -c

--------------------------------------------------------------------------------
PASSO 5: FONTES, DICIONÁRIOS, ESCRITÓRIO E EDITORES MODULARES
--------------------------------------------------------------------------------

5.1. Instalar dicionários Hunspell bilíngues (inglês e português brasileiro):
sudo pkg install -y textproc/hunspell textproc/en-hunspell textproc/pt_BR-hunspell

5.2. Instalar tipografia de alta densidade e símbolos Nerd Fonts:
sudo pkg install -y x11-fonts/jetbrains-mono x11-fonts/nerd-fonts

5.3. Instalar a suíte completa LibreOffice:
sudo pkg install -y editors/libreoffice

5.4. Executar a receita de integração do LibreOffice com tema escuro GTK3:
sh ~/Documents/Environment/Setup/common/office/office.sh

5.5. Executar a receita modular de editores (Emacs, Neovim, Vim, Helix, Micro):
sh ~/Documents/Environment/Setup/common/editors/editors.sh

5.6. Instalar ferramentas de leitura nativa de documentos, Poppler e DjVu:
sudo pkg install -y graphics/djvulibre graphics/poppler-utils print/pdftk textproc/hs-pandoc
sh ~/Documents/Environment/Setup/common/docs/typesetting.sh

--------------------------------------------------------------------------------
PASSO 6: KDE PLASMA 6, COMPOSITORES WAYLAND, GERENCIADORES X11 E EWM
--------------------------------------------------------------------------------

6.1. Otimizações de disco e cache do KDE Plasma 6:
balooctl6 disable 2>/dev/null || true
balooctl6 purge 2>/dev/null || true

sudo mkdir -p /usr/local/etc/xdg/plasma-workspace/env
cat << 'EOF' | sudo tee /usr/local/etc/xdg/plasma-workspace/env/kdevartmp.sh > /dev/null
#!/usr/bin/env sh
export KDEVARTMP="/tmp"
EOF
sudo chmod 0755 /usr/local/etc/xdg/plasma-workspace/env/kdevartmp.sh

6.2. Instalar a suíte completa de compositores Wayland e gerenciadores X11 leves:
sudo pkg install -y \
    x11-wm/openbox \
    x11-wm/cwm \
    x11-wm/matchbox-window-manager \
    x11-wm/sway \
    x11-wm/labwc \
    x11-wm/river \
    x11-wm/cage \
    sysutils/seatd \
    x11/foot

6.3. Instalar a suíte de ferramentas CMake completas:
sudo pkg install -y devel/cmake-core devel/cmake-man devel/cmake-gui

6.4. Instalar navegadores e cliente de correio eletrônico:
sudo pkg install -y www/firefox www/chromium mail/thunderbird

6.5. Compilar o compositor EWM (Emacs Wayland Manager):
sh ~/Documents/Environment/Setup/common/editors/ewm.sh

--------------------------------------------------------------------------------
PASSO 7: NOVIDADES DE SESSÃO GRÁFICA E COMUTAÇÃO DE USERLAND
--------------------------------------------------------------------------------
Recursos de sessão gráfica disponibilizados no repositório Shell:
- wwm: Wayland Window Manager (Sway) com barra superior interativa GTK3
  (wwm-bar) com botões em formato pílula GTK4/Qt6 sem colchetes (Web Browser,
  Terminal, Files, Emacs, Menu, Close, Exit), gerenciamento dinâmico de
  workspaces com botões de criação (+) e destruição (−), e fallback para swaybar.
- xwm: X11 Window Manager (Openbox) com suporte a redimensionamento em 8
  direções (bordas, cantos, grips) e atalho Alt+RightClick para janelas SSD
  (Terminal, Emacs, etc.), além do menu dinâmico categorizado (5 categorias).
- wgui / xgui: Lançadores de quiosque com abas dinâmicas auto-ocultáveis no
  Wayland (wgui-tabwatch) e barra superior dinâmica em Python 3 + GTK3 + X11
  (xgui-tabbar dock de 28px exibido sob >= 2 janelas) no Openbox X11 com 100%
  de paridade estética e tipográfica (#2b2b30 ativo, #1e1e22 inativo, 10pt Bold).
- Emacs Native Readers & Smart Open: Despachante inteligente 'o' / 'open' abrindo
  PDFs e DjVu ('o slide.pdf', 'o doc.djvu' a 192 DPI contínuo com modo escuro 'i'),
  e-books EPUB ('o book.epub'), bancos SQLite ('o db.sqlite3'), arquivos
  compactados ('o archive.zip') e processos ('procs' / 'htop') nativamente no Emacs.
- Ciclo Unificado de Cursor (1200ms): Sincronização temporal de 1200ms
  (600ms aceso / 600ms apagado) entre GTK3/GTK4, XTerm, Emacs, NeoVim e Vim.
- Pipeline 11-DE / 10-compositor: Detecção automática da cascata (KDE > GNOME >
  MATE > Cinnamon > XFCE > LXQt > LXDE > Budgie > Pantheon > Deepin > COSMIC)
  e harmonização determinística de temas GTK/Qt, cursores e fontes.
- ewm / exwm: Emacs Wayland Manager com frame limpo (tool-bar desabilitada) e
  EXWM com simulação contextual de teclas (emacs/wm-gui-simulation-keys vs
  emacs/wm-terminal-simulation-keys) conforme a classe da janela.

Comutação de userland:
- userland gnu     (ou gnu): Ativa utilitários GNU (gnubin / g-prefixed).
- userland bsd     (ou bsd): Ativa userland BSD nativo (bmake, bsdtar, mandoc).
- userland default (ou default): Restaura o userland padrão do sistema.
- userland status: Exibe o modo configurado em runtime.

--------------------------------------------------------------------------------
PASSO 8: SINCRONIZAÇÃO DE DOTFILES E AUDITORIA PÓS-REBOOT
--------------------------------------------------------------------------------

8.1. Sincronizar dotfiles do Profile com os caminhos canônicos do usuário:
~/.config/profile/profile.sh sync

8.2. Reiniciar o sistema para aplicar todos os tunables de bootloader e kernel:
sudo reboot

8.3. Comandos de auditoria imediata após o reinício:
sysctl vfs.zfs.arc.max vfs.zfs.arc.min kern.maxfiles kern.ipc.shmmax
sysctl compat.linuxkpi.i915_enable_psr compat.linuxkpi.i915_enable_psr2_sel_fetch compat.linuxkpi.i915_enable_fbc compat.linuxkpi.i915_enable_dc compat.linuxkpi.i915_enable_guc
dmesg | grep -iE "drmn0|guc|huc"
sudo vm list
vainfo
